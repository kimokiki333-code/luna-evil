      Selector Extraction

      This tool allows you to extract selectors from documents. A selector is a specific search term like an email address, an IP address, a domain name, a telephone number etc. The extracted selectors may be a starting point for further investigations.
      It supports the following file extensions:
      • Plaintext: CSV / LOG / TXT / INI
      • Web: HTML / HTM
      • Document: PDF, Word (DOC / DOCX / RTF), Excel (XLS / XLSX / ODS), PowerPoint (PPTX), Ebook (MOBI / EPUB / PRC)
